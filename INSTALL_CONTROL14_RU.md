# Установка CONTROL1.4 — только изменения

**Это патч, не весь проект и не готовый полный HTML.** P0 исправления включены. P1 — отдельно включаемое тестовое оформление, не завершённая визуальная приёмка референса. Исходный вид по умолчанию сохранён.

## Вариант1: у вас готовый PLAY.html1.3.1
Закройте игру. Распакуйте ZIP целиком. Нужен Python3.10+, сторонних библиотек не нужно.

```bash
python apply_control14.py --ready "ПУТЬ/IRON_DUNGEON_CONTROL_13_1_PLAY.html"
```

Принимается только точная проверенная1.3.1 (MD5 `525580833b56c8d164748b2cb5c27795`). Скрипт проверяет SHA256 и создаёт рядом **IRON_DUNGEON_CONTROL_14_PLAY.html**; исходный файл не меняется. Откройте именно новый PLAY14: прежний START.html/ярлык по-прежнему ведёт на13.1. Это структурная дельта, а не пересылка всей игры. Результат сверяется с настоящей пересборкой. Если файл1.1/изменён транспортом/другая ветка — скрипт откажет без записи. Не отключайте проверку.

В этой компактной автономной сборке только11 основных ресурсов. Арт-превью запускайте из source dev либо из явной сборки с дополнительными картами; при отсутствии этих карт игра сообщает об этом и оставляет прежнее оформление. Node/npm для данного способа не нужны. Не очищайте browser storage. Важно: saves привязаны к origin/адресу; для file:// разные имена HTML могут иметь разные хранилища. Updater переносит код, НЕ browser data. Подробнее ниже.

## Вариант2: у вас исходники1.3.1 (либо точные разрешённые хеши13RC2)
`ROOT` — папка, ВНУТРИ которой находится `foundation/`, не сама foundation.

```bash
python apply_control14.py --root "ROOT" --dry-run
python apply_control14.py --root "ROOT"
cd ROOT/foundation
npm ci
npm run build:single
```

Сначала проверяются ВСЕ before/after SHA. При локальных изменениях установка остановится, не перезатрёт чужую работу. Не копируйте целые папки поверх проекта. Installer сохраняет originals и journal в `.control14-backup-ДАТА-ВРЕМЯ` рядом с foundation. Ничего не удаляет. Исходники требуют сборки: старый standalone сам не изменится.

После source build основной готовый файл `foundation/IRON_DUNGEON_FOUNDATION.html`, вкладка CONTROL1.4. Public API `IronDungeon.build === 'CONTROL1.4-20261022'`; API version foundation-0.1 не номер поставки.

## Важно для старых сохранений и file://
При source update на прежнем HTTP(S) origin legacy slot читается там же. Открытие нового PLAY14.html через file:// может дать отдельное хранилище: предыдущая кампания не удалена, но новый файл её не видит. Не обещаю автоматический перенос между URL/браузерами.

Если требуется оставить прежний file URL для доступа к его сохранению:
1. Закрыть все вкладки игры. Скопировать старый13.1HTML в безопасную backup-папку и сверить его SHA с исходным; backup обязателен.
2. Сначала выполнить обычный `--ready`, проверить новый файл14. Затем **только по вашему явному выбору** скопировать его содержимое на ПРЕЖНИЙ путь/имя13.1HTML. Скрипт сам этого не делает. Текст title/API должен показывать14, хотя filename прежний.
3. Открыть прежний адрес, Esc → «Прежняя кампания (до1.4)». Сам legacy key остаётся read-only. Не чистить localStorage. file:// storage зависит от браузера; смена браузера/профиля/приватный режим не переносит данные.
4. Откат в таком варианте: закрыть14, восстановить проверенный backup13.1 на тот же исходный путь. Просто открыть backup под другим file URL может быть недостаточно для доступа к прежнему storage.

Это ручной вариант с сохранением backup, не автоматическое перезаписывание. Если выбираете новый URL — старый исходный13.1 и его прогресс остаются отдельно.

## Новая игра и продолжение
- Обычный запуск/restart — новое прохождение: RPG уровень1, основной CONTROL,120HP,0золота,2аптечки и штатные начальные сущности.
- Esc → прежнее подтверждение «Новая игра» — новый мир/задания/ресурсы; сохранение не удаляется.
- В паузе справа: «Продолжить сохранённую», «Предыдущее прохождение», «Прежняя кампания (до1.4)». Недоступные слоты отключены.
- Legacy ключ `iron_dungeon_artlab_v1` (для native ruins `iron_dungeon_save_v1`) не перезаписывается. Новый autosave — суффикс `_run14`, предыдущее прохождение — `_previous14`. Слоты2+legacy, это не неограниченная библиотека кампаний.
- При нехватке места для резервного слота игра не перезаписывает его: новое прохождение остаётся в памяти, показывается предупреждение.
- Старые сохранения не содержали карты/позиции/HP врагов: такие данные задним числом не восстановить. Новые сохраняют проверенные scene/player/enemy/destructible states. Летящие снаряды, выпавший неподобранный лут и временные VFX не сохраняются.

## Тестовый участок окружения — P1 не принят окончательно
Из source dev (`npm run dev`):
- `?renderer=canvas&environment14=sample` — небольшой8×8 участок брусчатки/стены;
- `?renderer=webgl&environment14=map` — экспериментальный общий вид, не финальная production интеграция;
- без `environment14` — исходное оформление, P0 исправления работают.

Для отдельного автономного арт-превью после build:
```bash
node scripts/build-single.mjs --environment14
```
Эта явная экспериментальная сборка содержит15 ресурсов, больше по памяти и не квалифицирована как основной релиз. Не меняйте свой основной готовый файл ею без backup. В2GB VM промежуточная версия с15 embedded resources дала kernelOOM при WebGL cave rebuild; это не полный pass. Основной11-resource вариант в том же WebGL cave-rebuild тоже упёрся в kernelOOM: уменьшение embedded набора не является исправлением GPU памяти. Доступные main WebGL проверки и Canvas пройдены; full GPU cave destruction не квалифицировано. Физический GPU/high12lights не проверены. Карты normal/roughness получены художественно из материала, а не измерены.

## Откат
Готовый файл: закрыть14 и открыть сохранённый13.1; его updater не менял.

Source:
```bash
python apply_control14.py --root "ROOT" --rollback "ROOT/.control14-backup-ДАТА-ВРЕМЯ"
```
Удаляются только точные ADD-файлы из journal при совпадающем hash; REPLACE восстанавливаются из originals. При последующих локальных правках откат откажет, чтобы их не затереть. Папки целиком не удаляются. Затем пересоберите прежний standalone. Browser saves/side slots не удаляются;1.3.1 использует свой прежний legacy slot.
